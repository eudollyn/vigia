# Identidade visual do Vigia

O simbolo e uma esfera dourada, ondas de voz e orbitas em tons de ambar, azul e verde, inspirado na interface animada do Vigia.

| Arquivo | Uso |
| --- | --- |
| vigia-logo.png | Marca com fundo transparente para interfaces, favicon e documentacao |
| vigia-app.png | Icone com fundo escuro para aplicativo e notificacoes |
| vigia.ico | Atalhos do Windows, em multiplas resolucoes |

Paleta original da interface: fundo #05060b, texto #f4f1ea, dourado #ffd9a0, ambar #ffb35c, azul #7cc4ff, verde #6fe3a5, vermelho #ff8a7a.

O painel mantem a animacao de halo, voz e estados de escuta. As imagens do painel e do assistente de configuracao sao incorporadas no HTML para funcionar tambem em acessos locais sem dependencias externas.
